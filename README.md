# AIIMS Office Model

Interactive 3D walkthrough of the AIIMS office (Three.js). `index.html` is the whole site — open it in a browser or deploy as a static site.

- `index.html` — the built viewer (self-contained except Three.js from cdn.jsdelivr.net)
- `source/` — viewer script, page markup, build/assemble scripts and the CC0 HDR used for lighting (Poly Haven "small_empty_room_3")

Deploy: Vercel → Add New → Project → import this repo → Deploy (no build settings needed).
